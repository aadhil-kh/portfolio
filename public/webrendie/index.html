For Windows and Linux

WebRendie

A desktop playground for web pages. Write HTML, CSS and JavaScript in the Monaco editor and see the result in a live preview as you type, with a console that shows logs, objects, tables and errors.

Get it from the Snap Store Get it from Microsoft

On Linux you can also install it from a terminal: sudo snap install webrendie

Features

  • Keep several projects, each with its own files, assets and settings
  • Inspect console output and run code in the page with the built-in console
  • Preview pages at phone, tablet and desktop sizes
  • Answer fetch calls with an offline mock API
  • Add libraries from cdnjs and serve a project on localhost for your browser
  • Open and edit standalone HTML files next to their CSS, scripts and images

Free, with optional Pro

WebRendie is free to use. Pro adds SCSS, Sass, TypeScript, JSX and TSX; split editor layouts; custom mock API collections; more than two projects; and project ZIP export.

Pro is a one-time license key, bought from the app (Main menu → Get Pro…) and activated there.
