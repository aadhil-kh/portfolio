# New Chmod Calculator, Smarter File Imports & Editor Enhancements

This update brings new developer tools, easier file handling, richer Markdown previews, enhanced code editing, and improved navigation.

### What's New

- **New Tool – Chmod Calculator:** Visually build Unix file permissions and generate ready-to-run `chmod` commands.
- **File Import & Open:** Drag and drop files directly into converters, validators, viewers, HTML/Markdown Preview, and the Diff Viewer.
- **Enhanced Markdown Preview:** Enjoy GitHub-style light and dark themes, smoother live rendering, and Mermaid diagrams that automatically adapt to the selected theme.
- **Improved Secret Key Generator:** Generate custom passwords with configurable minimum counts for uppercase letters, lowercase letters, digits, and symbols.
- **Enhanced Editor Experience:** Added syntax highlighting for TOON, TSV, and CSV, plus code folding for YAML, TOON, TOML, and HTML.
- **Refined Experience:** Redesigned the Diff Viewer toolbar, simplified the World Clock interface, and added keyboard shortcuts for faster navigation and tab management.
